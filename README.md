# DNA Paternity Testing Course

This course explains how DNA paternity testing works, from the basic science to the way results are compared and reported.

You do not need to know biology before starting. The lessons explain each topic in order and include examples and practice questions.

The examples in this course are fictional. Testing real samples and issuing official results require trained staff and an accredited laboratory.

## What you will learn

1. What DNA is and how children inherit it from their parents.
2. What STR markers are and how scientists read them.
3. How cheek swab samples are collected, labeled, and tracked.
4. How DNA is extracted from a sample and checked.
5. How PCR makes copies of selected DNA regions.
6. How a machine separates and reads DNA fragments.
7. How a DNA profile is prepared and checked.
8. How a child's DNA is compared with the mother's and the alleged father's.
9. How scientists calculate the strength of the DNA evidence.
10. How results are explained in a written report.

## How to use this course

- Start at Module 1 and work through the lessons in order.
- Each lesson explains new words before asking you to use them.
- Try the practice questions before checking the answers.
- Use the fictional examples provided in the course.
- Take your time and make sure you understand each lesson before moving on.

## Useful websites and tools

- [NIST STRBase](https://strbase.nist.gov/) explains STR markers and DNA testing terms.
- [AABB Relationship Testing](https://www.aabb.org/standards-accreditation/standards/relationship-testing-laboratories) provides information about professional relationship testing.
- [OSIRIS](https://github.com/iris-codes/OSIRIS) is software used to review forensic DNA data.
- [Biopython](https://github.com/biopython/biopython) provides tools for working with biological data in Python.
- [OpenStax Biology](https://openstax.org/details/books/biology-2e) is a free biology textbook.
- [OpenLearn: Inheritance](https://www.open.edu/openlearn/science-maths-technology/biology/inheritance-characters/content-section-0) introduces how traits are passed from parents to children.
